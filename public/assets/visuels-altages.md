# Visuels Altages

Préparés avec l’outil intégré de génération d’images. Les photographies sont illustratives : elles ne représentent pas l’équipe ou des réalisations identifiées d’Altages.

## Fichiers

- `altages-logo-transparent.png` : logo de la plaquette détouré sur fond transparent, bleu et or. Le site applique un traitement blanc par CSS pour les fonds sombres. L’extrait original reste dans `altages-logo.png`.
- `conformite.webp` : contrôle d’une installation électrique.
- `coordination.webp` : échange entre professionnels sur un site immobilier.
- `sinistres.webp` : inspection d’une fissure.

Les photographies ont été converties en WebP pour limiter leur poids sans modifier leur composition.
